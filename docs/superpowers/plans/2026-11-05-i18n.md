# 다국어(한국어·영어) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 새 탭 화면을 한국어·영어로 쓸 수 있게 한다. 처음엔 브라우저 언어를 따르고, 레일의 '설정' 패널에서 바꾸면 새로고침 없이 바로 바뀐다.

**Architecture:** `packages/ui/src/i18n/`에 `ko`·`en` 사전 객체와 모듈 단위 언어 상태를 둔다. 컴포넌트는 `useT()`(`useSyncExternalStore`)로 구독하고, React 밖 코드는 `getT()`로 부르는 순간의 언어를 읽는다. 언어는 `localStorage`에서 동기로 정해서 첫 렌더부터 맞는 언어로 그린다. 문구를 옮기는 작업은 "코드 속 한국어 가드" 테스트가 파일 단위로 몰아간다.

**Tech Stack:** TypeScript, React 18(`useSyncExternalStore`), Vitest + @testing-library/react(jsdom), pnpm 워크스페이스(`@tablign/core`·`@tablign/ui`·`apps/extension`), Chrome Extension MV3(`_locales`).

**Spec:** `docs/superpowers/specs/2026-11-05-i18n-design.md` · 시안 `docs/design/language-switch.html`(D안)

## Global Constraints

- **커밋은 사용자가 그 순간 허락할 때만.** 커밋 메시지는 fe-toolkit 컨벤션 `[타입] 명사형`(기능/수정/디자인/개선/문서/설정/테스트/기타), 50자 이내, 제목만. `feat(scope):` 금지. 브랜치는 `feat/i18n`.
- 언어는 `"ko" | "en"` 두 가지. 저장 키는 정확히 `localStorage["tablign.locale"]`. 다른 값은 없는 것으로 본다.
- 판단 순서: 저장값 → `navigator.languages`(비었으면 `[navigator.language]`)를 앞에서부터 보며 `ko`·`en`으로 시작하는 첫 값 → `"en"`.
- 사전 값은 **문자열** 또는 **문자열을 돌려주는 함수**만. `en`은 `Messages`(= `typeof ko`) 타입이라 빠진 키는 `pnpm lint`가 잡는다. `ko`에 `as const`를 붙이지 않는다(붙이면 `en`이 한국어 글자 그대로여야 하는 타입이 된다).
- 사전 섹션 이름 = 문구가 있는 파일 이름의 lowerCamelCase(`ImportBookmarksDialog.tsx` → `importBookmarksDialog`, `tabs.ts` → `tabs`). 예외 둘: 여러 파일이 같은 뜻으로 쓰는 낱말(취소·삭제·닫기·저장 등)은 `common`, 개인 조직·자동 스페이스 이름은 `org.personal`.
- 줄바꿈은 `\n` + 그리는 쪽 `whiteSpace: "pre-line"`. 문구 중간에 강조(`<b>`)가 끼면 `{name}` 같은 자리표시를 둔 문자열로 쓰고, 그리는 쪽에서 `split("{name}")`으로 나눠 사이에 요소를 끼운다.
- **번역된 문자열을 React state나 모듈 상수에 담지 않는다.** id·종류만 담고 그릴 때 사전에서 찾는다(언어를 바꾸면 바로 바뀌어야 하므로). 예외: DB에 저장하는 기본 이름(만드는 순간의 언어로 저장하는 게 스펙).
- 언어 이름은 번역하지 않는다: `LOCALE_NAMES = { ko: "한국어", en: "English" }`.
- 영어 문구: 문장형 대소문자(`New collection`, `Sign out`), 한국어 원문과 같은 길이감·같은 문장부호. 개수는 함수로 단·복수(`n === 1 ? "1 link" : \`${n} links\``).
- 코드 주석은 번역하지 않는다. UI 안에 안내 문구를 새로 넣지 않는다.
- 테스트 실행: `pnpm --filter @tablign/ui test`, `pnpm --filter @tablign/extension test`, core는 순수 함수만 `pnpm --filter @tablign/core exec vitest run src/__tests__/import-plan.test.ts src/__tests__/import-toby.test.ts src/__tests__/export.test.ts`(나머지 core 테스트는 원격 Supabase를 씀). 타입: `pnpm lint`.

```tsx
describe("detectLocale", () => {
  it.each([
    [null, ["en-US", "ko"], "en"], [null, ["ja", "ko-KR"], "ko"], [null, ["ja", "fr"], "en"],
    [null, [], "en"], ["ko", ["en-US"], "ko"], ["en", ["ko"], "en"], ["xx", ["ko"], "ko"],
  ])("저장 %s · 브라우저 %j → %s", (stored, langs, want) => {
    expect(detectLocale(stored as string | null, langs as string[])).toBe(want);
  });
});

describe("setLocale", () => {
  afterEach(() => { vi.restoreAllMocks(); setLocale("ko"); });

  it("저장하고 <html lang>을 바꾸고, useT를 쓰는 화면이 바로 다시 그려진다", () => {
    function Probe() { return <span>{useT().common.cancel}</span>; }
    render(<Probe />);
    expect(screen.getByText("취소")).toBeInTheDocument();
    act(() => setLocale("en"));
    expect(screen.getByText("Cancel")).toBeInTheDocument();
    expect(localStorage.getItem(LOCALE_KEY)).toBe("en");
    expect(document.documentElement.lang).toBe("en");
    expect(getT().common.cancel).toBe("Cancel");
  });

  it("저장소가 막혀 있어도 언어는 바뀐다", () => {
    vi.spyOn(Storage.prototype, "setItem").mockImplementation(() => { throw new Error("blocked"); });
    expect(() => setLocale("en")).not.toThrow();
    expect(getLocale()).toBe("en");
  });

  it("처음 불러올 때 저장된 언어로 시작한다", async () => {
    localStorage.setItem(LOCALE_KEY, "en");
    vi.resetModules();
    const fresh = await import("../i18n");
    expect(fresh.getLocale()).toBe("en");
    expect(document.documentElement.lang).toBe("en");
  });
});
```
