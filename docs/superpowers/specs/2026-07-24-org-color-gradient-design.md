# 조직 프로필 색상 — 그라데이션 지원 설계

## 배경 / 목표

조직(팀·개인) 프로필의 대표 색은 현재 **단색 하나**만 지정할 수 있다. 사용자가 원하면 **그라데이션**도 지정할 수 있게 하되, 고정 프리셋만 두지 않고 **커스텀 색처럼 직접 조정**할 수 있게 한다. 단색과 그라데이션을 하나의 편집기 흐름으로 통합한다.

핵심 이점: 색 필드(`organizations.color`)는 자유 문자열(`string | null`)이고 렌더 지점(레일·헤더·다이얼로그 미리보기)이 그 값을 그대로 CSS `background`로 쓰므로, **DB 스키마 변경 없이** 그라데이션 문자열을 담으면 바로 렌더된다.

## 저장 형식 (organizations.color)

- 단색: `#RRGGBB`  (기존과 동일 — 하위호환)
- 그라데이션: `linear-gradient(135deg, #START s%, #END e%)`
  - 각도는 **항상 135°** 고정.
  - 비율(스톱 위치)이 균등(0%·100%)이면 퍼센트를 생략: `linear-gradient(135deg, #START, #END)`.
- 렌더는 별도 분기 없이 `background: <color 문자열>` 그대로 사용(레일 `box()`, 헤더 배경, 다이얼로그 미리보기).

## 편집기 UX (확정)

색상 행의 **커스텀 슬롯**(기존 단색 커스텀 ＋ 슬롯을 대체)을 열면 편집기가 뜬다. 프리셋 단색 8칸 스와치는 빠른 선택용으로 유지.

편집기 구성:
1. **상단 토글**: 단색 / 그라데이션
2. **사각 미리보기 아바타**: 실제 프로필과 동일한 라운드 사각 + 아이콘. 실시간 갱신.
3. **그라데이션 바 + 인셋 핸들**:
   - 바는 결과 색을 그대로 표시.
   - 핸들은 바 **안쪽(인셋)** 에 위치 — 트랙 밖으로 튀어나오지 않음. 드래그 범위를 `[반지름, 폭−반지름]`으로 매핑해 0~100% 표현.
   - **단색 모드**: 가운데 핸들 1개.
   - **그라데이션 모드**: 시작·끝 핸들 2개.
4. **핸들 인터랙션**:
   - **탭** → 그 핸들 색을 고르는 **팔레트 팝오버**(SV 영역 + 색상 바 + HEX 입력, 기존 `ColorPicker` 재사용).
   - **드래그** → 스톱 위치(=영역 비율) 조정. 두 핸들 **최소 간격** 유지.
5. **스왑 버튼**(그라데이션): 시작 ↔ 끝 색 교환.
6. **HEX 표기는 팔레트에만** — 핸들/칩에는 색만(코드 중복 제거).

전환 규칙:
- 단색 → 그라데이션: 핸들 1 → 2, 끝 색은 시작색을 살짝 변형해 기본 채움, 스왑 등장.
- 시작 색 == 끝 색이면 사실상 단색과 동일(저장은 단색 HEX로 정규화).

## 적용 범위

팀 조직 **프로필 설정**과 개인 조직 **프로필 설정**(이번 브랜치에서 추가됨) **공통**으로 같은 편집기를 쓴다.

## 컴포넌트 / 모듈 구조

- **색 유틸** (`packages/ui/src/color.ts` 확장 또는 `gradient.ts` 신설):
  - `parseColorValue(value)` → `{ kind: "solid", hex } | { kind: "gradient", start, end, startPos, endPos }`
  - `buildColorValue(state)` → 저장 문자열(균등이면 퍼센트 생략, 시작=끝이면 단색 정규화)
  - 잘못된/알 수 없는 문자열은 안전한 기본값(단색)으로 폴백.
- **ColorGradientPicker** (신규, `packages/ui`): 토글·미리보기·바·인셋 핸들·팔레트 팝오버·스왑을 담은 편집기. `value: string`, `onChange(value: string)`, 미리보기용 `icon?` 입력.
  - 내부 팔레트는 기존 `ColorPicker` 재사용.
- **OrgFormDialog 통합**: 색상 섹션의 커스텀 슬롯을 `ColorGradientPicker` 진입점으로 교체. 프리셋 단색 스와치는 유지.
- **렌더 지점**: OrgRail·OrgHeader·다이얼로그 미리보기는 이미 문자열 background를 쓰므로 변경 최소(그라데이션 값이 그대로 적용되는지 확인만).

## 엣지 케이스 / 검증

- 기존 단색 hex 값 로드 시 단색 모드로 정상 표시(하위호환).
- 두 핸들 겹침 방지(최소 간격), 드래그 클램프.
- 탭 vs 드래그 구분(작은 이동 임계값).
- 팔레트 팝오버 바깥 클릭/Escape 닫기, 다이얼로그의 기존 팝오버들과 충돌 없는 z-index·바깥클릭 처리.
- 그라데이션 문자열 파싱 실패 방어.

## 테스트

- 색 유틸: `parseColorValue`/`buildColorValue` 단위테스트(단색·그라데이션·퍼센트 생략·시작=끝 정규화·불량 입력).
- 편집기: 토글 전환, 핸들 탭→팔레트 표시, 색 변경 반영, 비율 드래그 값 매핑, 스왑.
- OrgFormDialog: 그라데이션 지정 후 저장 시 `updateOrganization`에 그라데이션 문자열 전달, 단색 지정 시 hex 전달.

## 범위 밖(YAGNI)

- 3색 이상 다중 스톱, 각도 자유 조정(135° 고정), 방사형(radial) 그라데이션.
