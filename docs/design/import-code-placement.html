3. 빈 상태 — E2 리파인 4안

원안에서 손볼 지점 4개:

  1. 맥락 문장이 없다. 카드 3장만 떠 있어서 “컬렉션이 뭔지” 모르는 사람에겐 선택지만 있고 설명이 없습니다. 짧은 헤드라인 1줄을 얹습니다.
  2. ‘탭 12개’가 부정확하다. saveWindow는 창 하나 단위인데(NewTab.tsx:743) 창이 2개면 12개가 어디서 온 숫자인지 모릅니다 → “지금 창의 탭 5개”로 좁히고, 오른쪽 패널에서 대상 창을 하이라이트했습니다.
  3. primary 카드가 ‘선택된 상태’로 읽힌다. 카드 전체를 accentWeak로 칠하면 라디오처럼 보입니다 → 카드는 흰 배경, 아이콘만 accent.
  4. 누를 수 있다는 신호가 약하다. 우측 ›, hover 시 살짝 떠오르는 상태를 넣었습니다.
