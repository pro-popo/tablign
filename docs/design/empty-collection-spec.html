02

상태 변화

세 카드의 구조·높이·좌표가 모두 동일합니다. 그래서 창 수가 바뀌거나 담을 탭이 0개가 되어도 화면이 흔들리지 않고 문구와 활성 여부만 바뀝니다.

03

공유 코드로 추가

세 번째 카드가 여는 다이얼로그. 진입점 라벨과 제목이 같은 말이고, 확정 버튼은 제목과 겹치지 않는 「추가」입니다. 목적지는 현재 스페이스가 기본 선택돼 클릭 한 번이 줄어듭니다.

04

담을 수 있는 탭의 기준

lib/tabs.ts:9의 isHttp()가 url이 있고 http:// 또는 https://로 시작하는 탭만 통과시킵니다. 드래그 드롭·창 전체 저장·모든 저장 경로가 이 하나를 씁니다. permissions: ["tabs"]가 있어 url은 항상 채워지니, 실패는 사실상 스킴 때문입니다.

05

구현 체크리스트

마젠타 체크박스 두 개는 빈 상태와 무관하게 지금 존재하는 결함입니다 — 이 작업에서 같이 고쳐야 합니다.

이 문서가 대체하는 것 — 같은 세션의 이전 시안 세 개는 탐색 기록으로만 남습니다: import-code-placement.html(진입점 B·M2, 빈 상태 E1–E3), empty-collection-r2-actual.html(R2 실측 검토, 폭 판단이 뒤집힌 지점), empty-collection-r1.html(R1 확정 과정과 문구 후보 비교).
